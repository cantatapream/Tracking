# 초과근무수당 집계

월별 **초과근무수당 개인별 산출내역서** 엑셀 파일을 여러 개 골라서
`총 근무시간` 과 `시간외(시간)` 을 **월별 / 연도별로 합산**하는 매크로 엑셀입니다.

결과물: **`초과근무수당_집계.xlsm`**

---

## 쓰는 법

1. `초과근무수당_집계.xlsm` 을 연다.
2. 노란 경고줄이 뜨면 **[콘텐츠 사용]** 을 누른다. (매크로 허용)
3. **[엑셀 파일 선택 → 집계]** 버튼을 누른다.
4. 열린 창에서 월별 산정서 파일을 **Ctrl / Shift 로 여러 개** 고른다.
   2021년치부터 2025년치까지 한 번에 골라도 된다.
5. `집계결과` 시트에 표가 만들어진다. `처리내역` 시트에는 파일별 처리 결과가 남는다.

버튼이 안 보이면 `Alt + F8` → `RunAggregate` 를 실행해도 된다.

---

## 무엇을 읽는가

각 파일에서 **오른쪽 `급여 세부내용` 박스만** 읽습니다.
왼쪽 일자별 표(1~31일 칸과 `합계` 열)는 읽지 않습니다.

```
      급여 세부내용                <- 이 글자를 앵커로 찾는다
   총 근무시간 | 총 복무규정시간
        220    |       120         <- 총 근무시간  (라벨 바로 아래)
   시간외(시간)|       100         <- 시간외       (라벨 오른쪽)
   야간(시간)  |        56              (읽지 않음)
   휴일(일수)  |         2              (읽지 않음)
   출동가산    |         8              (읽지 않음)
```

같은 사람의 같은 항목이라도 왼쪽 `합계` 열과 `급여 세부내용` 박스의 값은 다를 수 있습니다.
필요한 것은 박스에 적힌 값이므로 **박스 쪽만 읽습니다.**

`급여 세부내용` 이라는 글자를 앵커로 찾기 때문에,
그 달의 일수(28 / 29 / 30 / 31일)에 따라 박스의 열 위치가 좌우로 밀려도,
인원 수가 몇 명이든 상관없이 전부 잡힙니다.

## 어느 시트를 읽는가

1. 파일 안의 모든 시트 중 **`초과근무수당 개인별 산출내역서` 제목이 있는 시트**를 후보로 잡는다.
2. 후보가 하나면 그 시트를 읽는다.
3. 후보가 둘 이상이면 시트명으로 고른다. 위에서부터 먼저 맞는 규칙을 쓴다.
   1. 시트명에 `경비함정` 이 들어있는 시트
   2. 공백을 지운 시트명에 `초과근무수당` 또는 `초간근무수당` 이 들어있고,
      `합계` 나 `내역` 은 들어있지 않은 시트

| 시트명 | 판정 |
|---|---|
| `경비함정` | 1순위로 선택 |
| `상황실,파출소,구조대 등` | 제외 |
| `5월 초간근무수당` | 2순위로 선택 |
| `5월 초과근무수당` | 2순위로 선택 |
| `4월 초과산정내역서` | 제외 |
| `5월 초과 합계 내역` | 제외 |

그래도 하나로 좁혀지지 않으면 집계에서 빼고 `처리내역` 시트에 사유를 남깁니다.

## 연도와 월

산정서마다 머리글 모양이 달라서, 아래 순서로 찾습니다.
먼저 찾아지는 것을 씁니다.

| 순서 | 연도 | 월 |
|---|---|---|
| 1 | `초과근무수당 일집계 현황(2025년 5월)` | 같은 곳 |
| 2 | 머리글의 `____년 __월` | 같은 곳 |
| 3 | 머리글의 네 자리 연도 (예: 관련근거 `1505함-0494-2024-05-00152`) | 머리글의 `__월` (예: `1505함 5월 출동현황`) |
| 4 | 파일 경로·파일명의 네 자리 연도 | 시트명, 그다음 파일명의 `__월` |

어디에서 찾았는지는 `처리내역` 시트의 **연월 출처** 칸에 남습니다.
`연:머리글 + 월:시트명` 처럼 나오니, 엉뚱하게 잡힌 파일이 있으면 바로 눈에 띕니다.
끝내 못 찾으면 집계에서 빼고 `연월 확인 필요` 로 남깁니다.

같은 연월 + 같은 함정 파일을 두 번 고르면 뒤엣것은 중복으로 보고 제외합니다.
같은 달이라도 함정이 다르면(1505함 / 1506함) 합산합니다.

## "Microsoft는 이 파일의 출처를 신뢰할 수 없기 때문에 매크로 실행을 차단했습니다"

파일이 깨진 것이 아닙니다. 인터넷에서 받은 파일이라 윈도우가 표시(Mark of the Web)를
붙여둔 것이고, 그러면 엑셀은 `[콘텐츠 사용]` 버튼도 없이 매크로를 막습니다.

1. 엑셀을 닫는다.
2. 파일 탐색기에서 `초과근무수당_집계.xlsm` **우클릭 → 속성**
3. **일반** 탭 맨 아래 `보안:` 옆의 **`차단 해제`** 를 체크
4. **적용 → 확인** 후 다시 연다.

`차단 해제` 가 아예 안 보이면 기관 정책으로 막아둔 경우입니다.
신뢰할 수 있는 위치를 지정하세요.

1. 엑셀 → **파일 → 옵션 → 보안 센터 → 보안 센터 설정**
2. **신뢰할 수 있는 위치 → 새 위치 추가** 에서 폴더를 하나 지정
3. 그 폴더에 `.xlsm` 을 옮겨놓고 연다.

## 매크로를 못 쓰게 되어 있다면

위의 방법이 다 막혀 있으면 매크로를 직접 넣어서 쓸 수 있습니다.
직접 만든 파일에는 Mark of the Web 이 붙지 않으므로 차단에 걸리지 않습니다.

1. 빈 엑셀 통합문서를 만들고 **Excel 매크로 사용 통합 문서(*.xlsm)** 로 저장한다.
2. `Alt + F11` → 메뉴 **파일 → 파일 가져오기** → `OvertimeReport_import.bas` 선택.
   (이 파일은 cp949 로 저장되어 있어 한글이 깨지지 않습니다.)
3. 엑셀로 돌아와 `Alt + F8` → `RunAggregate` 실행.

## 파일 구성

| 경로 | 설명 |
|---|---|
| `초과근무수당_집계.xlsm` | 결과물. 이것만 있으면 됩니다 |
| `OvertimeReport.bas` | 매크로 원본 (UTF-8, 읽기용) |
| `OvertimeReport_import.bas` | 매크로 원본 (cp949, VBA 편집기 가져오기용) |
| `sample/` | 산정서와 같은 모양으로 만든 시험용 파일 |
| `tools/` | `.xlsm` 을 만들어내는 파이썬 스크립트 |

`.bas` 를 고친 뒤 `.xlsm` 을 다시 만들려면:

```bash
pip install openpyxl
python3 overtime/tools/build_xlsm.py
```

`tools/` 안에는 `.xlsm` 에 VBA 프로젝트를 심기 위한 코드가 들어 있습니다.

- `ovba.py` — [MS-OVBA] 압축/해제
- `cfb.py` — OLE 복합 문서([MS-CFB]) 작성
- `vbaproject.py` — `vbaProject.bin` 조립
- `build_xlsm.py` — 시트·버튼을 붙여 `.xlsm` 으로 포장
- `selftest.py` — `sample/` 을 만들고 스캔 로직을 검증
- `vbacheck.py` — VBA 예약어 충돌, 블록 짝, 인자 개수 등 정적 점검

`sample/` 에는 서로 다른 세 가지 머리글·시트명 모양의 표본이 들어 있습니다.
`일집계 현황` 줄이 있는 모양, 28일치(박스 열이 밀린 경우),
그리고 `경비함정` / `상황실,파출소,구조대 등` 두 시트가 함께 있는 모양입니다.

## 검증 범위

이 환경에는 엑셀이 없어서 **엑셀에서 직접 열어본 것은 아닙니다.** 대신:

- 생성한 `vbaProject.bin` 을 `olefile` 과 `oletools`(olevba)로 다시 읽어
  네 개 모듈이 모두 인식되고 매크로 원본이 **한 글자도 다르지 않게** 복원되는 것을 확인했습니다.
- MS-OVBA 압축은 자체 해제기와 `oletools` 해제기 양쪽으로 왕복 검증했습니다.
- 스캔 로직은 `selftest.py` 로 검증했습니다.
  산정서와 같은 모양의 5월(31일)·2월(28일) 파일을 만들어,
  박스 열 위치가 밀려도 값을 제대로 찾는지, 왼쪽 `합계` 열과 박스 값이 다른 사람에 대해
  박스 값을 읽는지,
  `5월 초과 합계 내역` 같은 시트를 건너뛰는지 확인합니다.

처음 열 때 이상이 있으면 위의 **매크로를 못 쓰게 되어 있다면** 절차로 바로 쓸 수 있습니다.
